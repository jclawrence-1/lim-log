# LIM remote log: demo viewer

Demo page for a LIM remote's log QR code. Sample data only. The readings travel in the link's `#` part and never reach this server.
Format and source: kept in MainPro's LIM reference folder (`_Universal Remote\log-qr\`).
`404.html` is a copy of `index.html`, so links of the form `/lim-log/p/<panel code>#1.<payload>` open the viewer.
